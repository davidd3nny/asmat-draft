# Əsmət: сайт-черновик

Одна страница как разворот меню: слева кухня, справа винная карта, а пары «блюдо + вино» соединяет нить. Три языка (AZ, RU, EN), часы кухни и бара по времени Баку, отбор вин по бокалам и местным, бронь через WhatsApp.

Сайт собирается сам. Вы меняете один файл с данными, `sites/asmat/data.json`, а GitHub через 1–2 минуты публикует новую версию:
**https://davidd3nny.github.io/asmat-draft/**

## Что где лежит

| Папка или файл | Что внутри | Кто меняет |
|---|---|---|
| `sites/asmat/data.json` | всё меню и цены, пары, часы, телефон, адрес, тексты на трёх языках | Вы |
| `sites/asmat/index.html` | разметка страницы | при доработке дизайна |
| `sites/asmat/style.css` | оформление | при доработке дизайна |
| `sites/asmat/app.js` | поведение: половины, нить пары, отбор вин, режим «Пары» | при доработке |
| `sites/asmat/art/defs.svg` | значки | не трогать |
| `sites/asmat/fonts.json`, `fonts/` | шрифты и их лицензии (OFL) | не трогать |
| `shared/core.js` | общие помощники: язык, время в Баку, цены | не трогать |
| `build.py` | сборщик: склеивает всё в один файл и проверяет данные | не трогать |
| `.github/workflows/deploy.yml` | робот «Сайт»: собирает и публикует | не трогать |

## Первый запуск (один раз)

1. **Settings → Pages**, поле **Source**: выберите **GitHub Actions**. Больше ничего не нажимайте: робот уже лежит в репозитории, кнопки Configure у предложенных шаблонов не нужны.
2. **Actions**: первый запуск робота «Сайт» мог упасть до шага 1. Откройте его и нажмите **Re-run all jobs**.
3. Через минуту сайт откроется по ссылке выше.

## Как править data.json

Откройте файл на github.com и нажмите карандаш (**Edit**). После правки: **Commit changes**.

Правила JSON, их всего четыре:
- тексты и названия полей в двойных кавычках: `"name"`;
- цены числом, без кавычек: `9`, `12.5`. Знак ₼ сайт ставит сам;
- между элементами запятая, после последнего элемента в списке запятой нет;
- комментариев в JSON не бывает.

Ошиблись, и сайт не сломается: робот откажется собирать, на сайте останется прошлая версия, а в отчёте будет по-русски написано, что и в какой строке не так (подробнее в конце).

### Блюдо

```json
{"id": "c1", "price": 9, "name": {"az": "Trio aperitiv | zeytun, ədviyyatlı badam və kartof çipsi", "ru": "Трио аперитив | оливки, миндаль в специях, картофельные чипсы", "en": "Aperitif Trio | olives, spiced almonds, house-made potato chips"}},
```

- До черты ` | ` название, после неё пояснение мелким шрифтом.
- Текст нужен на всех трёх языках, иначе сборка остановится.

### Вино

```json
{"id": "w9", "name": "Astoria Clamore", "org": "Italy · Veneto", "grp": "Sauvignon Blanc", "glass": 11, "bottle": 55},
```

| Поле | Что это | Обязательно? |
|---|---|---|
| `glass` | цена бокала | хотя бы одна цена |
| `bottle` | цена бутылки | хотя бы одна цена |
| `org` | страна · регион | нет |
| `grp` | сорта винограда | нет |
| `local` | `true` для азербайджанского вина (фильтр «Азербайджан») | нет |
| `vint` | несколько годов урожая вместо `bottle`: `[{"y": 2007, "bottle": 1100}, {"y": 2012, "bottle": 1000}]` | нет |

Вино без `glass` продаётся только бутылкой и не попадает в фильтр «Бокалами».

### Новая позиция и id

Скопируйте соседнюю строку целиком, с запятой в конце, и дайте ей **новый id**. Буква показывает раздел:

| Раздел | id |
|---|---|
| Холодные закуски | `c1`…`c20` |
| Горячие закуски | `h1`…`h7` |
| Основные блюда | `m1`…`m5` |
| Гарниры | `s1`…`s3` |
| Паста | `p1`…`p2` |
| Пицца | `z1`…`z6` |
| Десерты | `d1`…`d6` |
| Вина и напитки | `w1`…`w59` |

Новое холодное блюдо получит `c21`, новое вино `w60`. Старые id не меняйте и не используйте повторно: по ним пары находят свои блюда и вина.

Чтобы убрать позицию, удалите её строку. Если она стоит в паре, сборка подскажет, какую пару сначала поменять.

## Пары «блюдо + вино»

```json
{"dish": "c1", "drink": "w59", "why": {"az": "Duzlu qəlyanaltı, soyuq köpük. Alkoqolsuz.", "ru": "Солёная закуска и холодные пузырьки. Без алкоголя.", "en": "Salty snacks, cold bubbles. No alcohol."}},
```

- `dish`: id блюда, `drink`: id вина, `why`: одна фраза, почему они вместе.
- Цена пары = блюдо + бокал, поэтому у вина в паре обязательно есть `glass`.
- Каждое блюдо и каждое вино может стоять только в одной паре.
- «Пара вечера» меняется сама каждый вечер, по кругу по списку. Новый вечер начинается в момент закрытия бара.

## Часы, телефон, адрес

```json
"kitchen": {"hours": {"open": "17:00", "close": "01:00"}, ...},
"bar":     {"hours": {"open": "17:00", "close": "01:00"}, ...},
```

- Время Баку. Закрытие после полуночи пишется как есть: `"01:00"`.
- По этим часам сайт сам пишет «Готовим до…», «Открыты до…», «Закрыта до…».
- Если кухня перестаёт принимать заказы раньше закрытия, добавьте в `kitchen` два поля, рядом с `hours`: `"lastFrom": "00:00", "lastOrders": "00:30"`. С 00:00 сайт напишет «Последние заказы до 00:30», после 00:30 «Закрыта. Винная карта открыта.» Пока владелец время не назвал, полей нет, и кухня работает до закрытия.

| Поле | Что это |
|---|---|
| `phone` | номер для звонка и WhatsApp: `+994503005254`, без пробелов |
| `phoneDisplay` | как номер выглядит на сайте |
| `address` | адрес на трёх языках |
| `mapUrl` | ссылка «Открыть на карте» |
| `instagram` | `handle` (как показывать) и `url` |
| `ui` | все подписи интерфейса на трёх языках, в том числе сервисный сбор (`fee`) |

## Когда сайт станет настоящим

1. В `data.json` поставьте `"draft": false`. Исчезнет плашка «черновик», а `robots.txt` откроет сайт поисковикам.
2. В `sites/asmat/index.html` удалите строку `<meta name="robots" content="noindex">` с комментарием над ней и уберите `(qaralama)` из `<title>`. Без этого шага Google сайт так и не покажет.
3. Подключите домен заведения по инструкции «Переезд сайта на домен клиента: GitHub Pages → Cloudflare».

## Собрать на своём компьютере

```bash
python3 build.py asmat
open out/asmat.html
```

Подойдёт любой Python 3, в том числе тот, что ставится вместе с Xcode Command Line Tools. Сторонние библиотеки не нужны.

Для проверки к адресу страницы можно дописать:

| Параметр | Что делает |
|---|---|
| `?lang=ru` | язык: `az`, `ru`, `en` |
| `?at=00:45` | показать сайт так, будто в Баку сейчас 00:45 |
| `?day=5` | будто сегодня пятница (`0` воскресенье … `6` суббота) |

Параметры складываются: `?lang=en&at=18:30`.

## Если что-то пошло не так

**Робот во вкладке Actions стал красным.** На сайте осталась прошлая версия, гости ничего не заметили. Откройте упавший запуск, шаг «Собрать сайт»: там по-русски написано, что не так. Частые причины:
- лишняя или пропущенная запятая;
- цена в кавычках или с текстом (`"12 AZN"`);
- удалено блюдо или вино, которое стоит в паре.

**Правка прошла, а сайт старый.** GitHub Pages держит копию страницы до 10 минут. Обновите с очисткой кэша (Cmd + Shift + R) или откройте адрес с `?v=2` в конце.
